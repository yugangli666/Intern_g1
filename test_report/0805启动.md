# 0805 InternNav 实机启动流程

本文记录 2026-08-05 关机重启后实机测试采用的完整启动流程。整体链路为：

```text
宿主机 Livox 雷达
宿主机 GMSL 双路相机
  -> nav_vln_dev 容器启动 GLIM + Nav2 + message_forward
  -> internnav_server2 容器启动 InternNav 推理服务
  -> preflight 检查
  -> run_minimal_closed_loop.sh 实机运动测试
```

所有 ROS 2 终端统一设置：

```bash
source /opt/ros/jazzy/setup.bash
export ROS_DOMAIN_ID=33
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
```

0805 与 0804 的主要区别是相机使用方式发生了切换：

```text
0805 前半段：
  主相机 PRIMARY_RGB_TOPIC=/camera/cam_high/image_raw
  辅相机 SECONDARY_RGB_TOPIC=/camera/cam_high_extra/image_raw

0805 后半段及后续默认：
  主相机 PRIMARY_RGB_TOPIC=/camera/cam_high_extra/image_undistorted
  辅相机 SECONDARY_RGB_TOPIC=/camera/cam_high/image_raw
```

后续实机测试默认使用 undistorted 主相机。

## 1. 启动 Livox 雷达

运行位置：宿主机。

```bash
cd /home/spirit-ai/thor_livox_mid360s_installer/livox_ws
source /opt/ros/jazzy/setup.bash
source install/setup.bash

export ROS_DOMAIN_ID=33
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp

ros2 launch livox_ros_driver2 msg_MID360s_launch.py
```

检查：

```bash
ros2 topic hz /livox/lidar
ros2 topic hz /livox/imu
```

预期：`/livox/lidar` 约 10 Hz，`/livox/imu` 持续有数据。Nav2 配置中点云话题使用 `/livox/lidar`，实机测试前不要漏启动雷达。

## 2. 启动 GMSL 双路相机

运行位置：宿主机。

```bash
source /opt/ros/jazzy/setup.bash
source ~/pygmsl/ros2/install/setup.bash

export ROS_DOMAIN_ID=33
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp

ros2 launch gmsl gmsl_multi_camera_launch.py \
  device_ids:=4,5 \
  output_width:=1408 \
  output_height:=1280
```

检查原始相机：

```bash
ros2 topic hz /camera/cam_high/image_raw
ros2 topic hz /camera/cam_high_extra/image_raw
```

0805 实测：两路原始图像约 30 Hz。

## 3. 检查 undistorted 主相机

0805 后半段将主相机切为：

```text
/camera/cam_high_extra/image_undistorted
```

检查：

```bash
ros2 topic info /camera/cam_high_extra/image_undistorted
ros2 topic echo /camera/cam_high_extra/image_undistorted --once
ros2 topic hz /camera/cam_high_extra/image_undistorted
```

0805 实测该话题信息：

```text
type: sensor_msgs/msg/Image
frame_id: cam_high_extra_undistorted
encoding: rgb8
size: 1408 x 1280
rate: about 30 Hz
QoS: BEST_EFFORT
publisher: omni_extra_undistort_publisher
```

如果该话题没有数据，先不要跑实机 VLN；需要恢复 undistort publisher 或暂时回退到 `/camera/cam_high/image_raw`。

## 4. 启动 GLIM + Nav2

运行位置：`nav_vln_dev` 容器内。

```bash

```

等待日志出现类似：



```text

/velocity_smoother active [3]
/collision_monitor active [3]
moz1/map -> moz1/base_link TF 可用
/moz1/odom_global 持续有数据
```

## 10. 测试后停止底盘

每次实机测试结束后都补发零速度。运行位置：`nav_vln_dev` 容器内。

```bash
source /opt/ros/jazzy/setup.bash
source install/setup.bash

export ROS_DOMAIN_ID=33
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp

timeout 1 ros2 topic pub /cmd_vel geometry_msgs/msg/Twist "{}" -r 10 >/dev/null 2>&1 || true
timeout 1 ros2 topic pub /cmd_vel_nav geometry_msgs/msg/Twist "{}" -r 10 >/dev/null 2>&1 || true
timeout 2 ros2 topic echo /mx_base_state --once 2>/dev/null || true
```

如果底盘异常继续运动，立即使用人工急停。

## 12. 0805 关键注意事项

1. 底盘速度链路已经验证可动：`/cmd_vel_nav -> /cmd_vel_smoothed -> /cmd_vel -> /mx_base_vel_command`。
2. `/robot_cmd_service` 在 0805 测试时不可用，因此实机测试使用 `USE_BASE_MOTION_SERVICE=0`。
3. 转向使用 `SPIN_CONTROL_MODE=fallback_turn`，并设置 `COMMAND_ANGULAR_SIGN=1.0`。
4. 相机默认使用 `/camera/cam_high_extra/image_undistorted` 作为主相机；早期原始相机测试结果不要和后期 undistorted 测试混在一起比较。
5. 多数目标测试可以产生实际运动，但模型距离判断仍不稳定，常见最终状态为 `HOLD` 或 `forward motion timeout`，所以测试时必须有人现场观察并准备急停。
