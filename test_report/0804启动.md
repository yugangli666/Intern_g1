# 0804 InternNav 实机启动流程

本文记录 2026-08-04 关机重启后重新跑通的 InternNav 实机启动与测试流程。核心结论是：雷达和 GMSL 双路相机由宿主机启动，导航在 `nav_vln_dev` 容器内启动，再运行 InternNav 推理服务、motion preflight 和实机 VLN 客户端，可以稳定恢复实机运动链路。

本次成功验证了两类测试：

```text
Move forward slowly.                         -> 前进约 0.5 m
Find the red fire extinguisher cabinet ...   -> 转向搜索 + 前进
```

所有 ROS 2 终端统一使用：

```bash
export ROS_DOMAIN_ID=33
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
```

## 6. 前进 0.5 m 测试

0804 第一次使用 `MAX_INFERENCES=2` 时，模型两次都输出 `discrete_turn/spin`，由于 `SKIP_TURN_ONLY_MOTION=1`，客户端正确跳过，实机保持不动。

成功版本将推理次数放宽到 6，但仍只允许 1 个前进 step：

```bash
cd /workspace/Intern_g1
source /opt/ros/jazzy/setup.bash
source /workspace/nav_ws/install/setup.bash

export ROS_DOMAIN_ID=33
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
export PRIMARY_RGB_TOPIC=/camera/cam_high/image_raw
export SECONDARY_RGB_TOPIC=/camera/cam_high_extra/image_raw
export ODOM_TOPIC=/moz1/odom_global
export SERVER_HEALTH_URL=http://127.0.0.1:5801/health

RESULT_DIR=/workspace/Intern_g1/experiment_records/real_motion_forward_05m_retry_$(date +%Y%m%d_%H%M%S) \
INSTRUCTION='Move forward slowly.' \
ENABLE_MOTION=1 \
MOTION_ARMED=YES \
ALLOW_FORWARD_MOTION=1 \
FORWARD_ARMED=YES \
ALLOW_LEGACY_IDLE_STACK=1 \

MAX_MOTION_STEPS=1 \

ANGULAR_SPEED=0.05 \
```

## 8. 测试后停稳

每次实机测试结束后，额外发布停任务和零速度：

```bash
cd /workspace/Intern_g1
source /opt/ros/jazzy/setup.bash
source /workspace/nav_ws/install/setup.bash

export ROS_DOMAIN_ID=33
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp

python3 - <<'PY'
import time
import rclpy
from geometry_msgs.msg import Twist
from std_msgs.msg import Bool

rclpy.init()
node = rclpy.create_node('internnav_post_test_stop')
cmd_nav = node.create_publisher(Twist, '/cmd_vel_nav', 10)
cmd = node.create_publisher(Twist, '/cmd_vel', 10)
stop = node.create_publisher(Bool, '/robot_nav_stop_task', 10)
zero = Twist()
msg = Bool()
msg.data = True

end = time.time() + 1.5
while time.time() < end:
    cmd_nav.publish(zero)
    cmd.publish(zero)
    stop.publish(msg)
    rclpy.spin_once(node, timeout_sec=0.02)
    time.sleep(0.05)

node.destroy_node()
rclpy.shutdown()
print('[OK] published stop + zero velocity')
PY
```

## 10. 0804 关键经验

```text
1. 重启后雷达必须在宿主机启动，容器内只检查 ROS 话题。
2. Nav2 启动后必须等待 GLIM relocalization 和 Managed nodes are active。
3. motion preflight 必须通过后才启动实机测试。
4. Move forward slowly. 首轮可能输出离散转向；如启用 SKIP_TURN_ONLY，需要放宽 MAX_INFERENCES 等 trajectory_forward。
5. 红色灭火器箱测试需要允许 fallback_turn 实际执行，否则只会看到模型搜索但机器人不转。
6. 当前实机运动链路已验证为 /cmd_vel_nav -> /cmd_vel_smoothed -> /cmd_vel -> /mx_base_vel_command。
7. 本次灭火器箱测试未证明模型级 STOP 到达能力，只证明搜索、转向、前进链路可执行。
```
