# InternNav 实机 VLN 启动流程

本文档记录 2026-07-23 在 Y03 / MOZ1-03-Y 环境中验证过的启动顺序。核心原则是先让传感器、定位和单套 Nav2 稳定，再启动 InternNav 推理服务，最后运行 dry-run 或低速实机测试。

## 0. 全局约定

所有 ROS 2 终端必须保持一致：

```bash
export ROS_DOMAIN_ID=33
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
```

常用工作目录：

```bash
cd /workspace/Intern_g1
```

常用输入/输出话题：

```text
主相机: /moz_robot/camera/cam_high/image_raw
副相机: /moz_robot/camera/cam_high_extra/image_raw
里程计: /moz1/odom_global
推理服务: http://127.0.0.1:5801/eval_dual
健康检查: http://127.0.0.1:5801/health
InternNav 输出: /cmd_vel_nav
底盘链路: /cmd_vel_nav -> /cmd_vel_smoothed -> /cmd_vel -> /mx_base_vel_command
dry-run 输出: /internnav/dry_run_cmd_vel
```

安全边界：

```text
无运动测试: ENABLE_MOTION=0, ALLOW_FORWARD_MOTION=0
实机低速测试: ENABLE_MOTION=1, MOTION_ARMED=YES, ALLOW_FORWARD_MOTION=1, FORWARD_ARMED=YES
不要直接向 /cmd_vel 或 /mx_base_vel_command 手工发布速度
不要关闭急停话题和最终零速度停稳逻辑
```

## 1. 清理重复 Nav2 栈

在 `internnav_server2` 容器内先停止 InternNav 自己 PID 文件记录的进程：

```bash
cd /workspace/Intern_g1
source /opt/ros/jazzy/setup.bash
source /workspace/nav_ws/install/setup.bash
export ROS_DOMAIN_ID=33
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp

bash scripts/realworld/stop_internnav_nav.sh
```

检查是否有重复导航节点：

```bash
ros2 node list --no-daemon | sort | uniq -c | grep -E \
'controller_server|velocity_smoother|collision_monitor|message_forward|nav_executor|planner_server|smoother_server|behavior_server|bt_navigator|waypoint_follower|route_server|docking_server|lifecycle_manager_navigation'
```

验收标准：

```text
controller_server = 1
velocity_smoother = 1
collision_monitor = 1
message_forward = 1
planner_server / smoother_server / behavior_server / bt_navigator / waypoint_follower / route_server / docking_server / lifecycle_manager_navigation 均不超过 1
```

如果发现重复 Nav2 栈，优先在启动它的宿主机、容器或 launch 终端停止多余实例。不要对 `/controller_server`、`/collision_monitor` 这类同名节点直接做 lifecycle shutdown，因为多实例时服务名有歧义。

### 4.1 0723 实测运行时 Nav2 参数

0723 实机测试中，collision monitor 的 `/livox/lidar` 原始点云包含 `(0,0,0)` 和自车近点，直接触发 `CircleStop`。最终采用运行时参数过滤自点，而不是关闭 collision monitor：

```yaml
collision_monitor:
  ros__parameters:
    polygons: ["CircleStop", "CircleLimit"]
    CircleStop:
      radius: 0.55
      action_type: "stop"
      min_points: 4
      enabled: True
    CircleLimit:
      radius: 0.65
      action_type: "slowdown"
      slowdown_ratio: 0.10
      enabled: True
    pointcloud:
      topic: "/livox/lidar"
      min_height: 0.45
      max_height: 1.8
      min_range: 0.0
      enabled: true
```

速度平滑器低速限制：

```yaml
velocity_smoother:
  ros__parameters:
    max_velocity: [0.12, 0.08, 0.25]
    min_velocity: [0.0, -0.08, -0.25]
    velocity_timeout: 0.30
```

## 6. 实机前统一预检

传感器检查：

```bash
ros2 topic hz /moz_robot/camera/cam_high/image_raw
ros2 topic hz /livox/lidar
ros2 topic hz /moz1/odom_global
ros2 run tf2_ros tf2_echo moz1/map moz1/base_link
```

Nav2 节点检查：

```bash
ros2 node list --no-daemon | sort | uniq -c | grep -E \
'controller_server|velocity_smoother|collision_monitor|message_forward|nav_executor'
```

控制链路静止基线：

```bash
python3 - <<'PY'
import time, math
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import Twist, Vector3

class N(Node):
    def __init__(self):
        super().__init__('internnav_quiet_probe')
        self.tw = {t: [] for t in ['/cmd_vel_nav', '/cmd_vel_smoothed', '/cmd_vel']}
        self.base = []
        for t in self.tw:
            self.create_subscription(Twist, t, lambda m, t=t: self.tw[t].append((m.linear.x, m.linear.y, m.angular.z)), 10)
        self.create_subscription(Vector3, '/mx_base_vel_command', lambda m: self.base.append((m.x, m.y, m.z)), 10)

rclpy.init()
n = N()
end = time.time() + 3
while time.time() < end:
    rclpy.spin_once(n, timeout_sec=0.05)
for t, vals in n.tw.items():
    non = sum(1 for x, y, z in vals if abs(x) > 1e-4 or abs(y) > 1e-4 or abs(z) > 1e-4)
    print(t, 'samples', len(vals), 'nonzero', non)
non = sum(1 for x, y, z in n.base if abs(x) > 1e-4 or abs(y) > 1e-4 or abs(z) > 1e-4)
print('/mx_base_vel_command', 'samples', len(n.base), 'nonzero', non)
n.destroy_node()
rclpy.shutdown()
PY
```

验收：所有控制话题 `nonzero=0`。

## 8. 低速实机前进测试

0723 最终成功命令如下。该命令保留软件限速、限距、超时和最终停稳；没有关闭急停链路。

```bash
cd /workspace/Intern_g1
source /opt/ros/jazzy/setup.bash
source /workspace/nav_ws/install/setup.bash
export ROS_DOMAIN_ID=33
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp

RESULT_DIR=/workspace/Intern_g1/experiment_records/real_motion_forward_05m_$(date +%Y%m%d_%H%M%S) \
SERVER_URL=http://127.0.0.1:5801/eval_dual \
PRIMARY_RGB_TOPIC=/moz_robot/camera/cam_high/image_raw \
SECONDARY_RGB_TOPIC=/moz_robot/camera/cam_high_extra/image_raw \
ODOM_TOPIC=/moz1/odom_global \
INSTRUCTION='Move forward slowly.' \
ENABLE_MOTION=1 \
MOTION_ARMED=YES \
ALLOW_FORWARD_MOTION=1 \
FORWARD_ARMED=YES \
ALLOW_LEGACY_IDLE_STACK=1 \
SKIP_TURN_ONLY_MOTION=1 \
MAX_INFERENCES=2 \
MAX_MOTION_STEPS=1 \
LINEAR_SPEED=0.05 \
MAX_FORWARD_DISTANCE=0.50 \
MAX_SPIN_DEGREES=2.0 \
ANGULAR_SPEED=0.05 \
MAX_BASE_LINEAR=0.08 \
MAX_BASE_ANGULAR=0.08 \
MOTION_TIMEOUT=18.0 \
PREFLIGHT_WAIT=5.0 \
bash scripts/realworld/run_minimal_closed_loop.sh
```

`SKIP_TURN_ONLY_MOTION=1` 的含义是：如果模型第一帧只输出离散转向动作，则跳过该 turn-only 微动作并继续等下一次 forward/trajectory 输出。它不会把转向动作伪装成前进动作。

## 9. 结果文件

每次测试会在 `experiment_records/<name>_<timestamp>/` 下保存：

```text

```

常用检查：

```bash
cat experiment_records/<result_dir>/summary.json
cat experiment_records/<result_dir>/events.jsonl
```

低速实机测试通过标准：

```text
模型至少一次输出 trajectory 或可解析前进动作
/cmd_vel_nav、/cmd_vel_smoothed、/cmd_vel、/mx_base_vel_command 出现受限低速前进命令
max_linear 不超过配置上限
odom 位移接近目标距离且不明显超限
最终状态为 MOTION_COMPLETE
运行后控制链路恢复零输出
```
