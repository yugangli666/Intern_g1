# InternNav 实机 VLN 启动指南

本文档记录当前项目在实机上运行 InternNav VLN 推理与运动闭环的启动方法，包含一键启动和分开启动两种方式。

当前默认链路：

```text
相机 RGB -> InternNav HTTP 推理服务 -> direct control client
-> discrete_action / trajectory
-> fallback turn 或 MPC/Pure Pursuit hybrid tracking
-> /cmd_vel_nav -> velocity_smoother -> collision_monitor
-> /cmd_vel -> message_forward -> /mx_base_vel_command
```

## 运行前约定

项目目录：

```bash
cd /workspace/Intern_g1
```

默认话题：

```text
主相机: /moz_robot/camera/cam_high/image_raw
辅相机: /moz_robot/camera/cam_high_extra/image_raw
里程计: /moz1/odom_global
推理服务: http://127.0.0.1:5801/eval_dual
健康检查: http://127.0.0.1:5801/health
```

推荐控制参数：

```text
CONTROL_MODE=mpc_tracking
TRAJECTORY_TRACKER=hybrid
COMMAND_ANGULAR_SIGN=1.0
SPIN_CONTROL_MODE=fallback_turn
MPC_DESIRED_V=0.10
MPC_V_MAX=0.15
MPC_W_MAX=0.25
```

说明：

- `COMMAND_ANGULAR_SIGN=1.0` 表示遵循 ROS 约定，`angular.z > 0` 为左转。
- `TRAJECTORY_TRACKER=hybrid` 表示优先使用 MPC，MPC 异常或发散时回退到 Pure Pursuit。
- 当前一键脚本不会启动相机，只检查相机话题是否已有数据。
- 当前代码未启用复合指令显式两阶段参数，`Turn around, ...` 类指令仍由模型和客户端 fallback turn 逻辑处理。

## 一键启动

相机需要先由外部 `agent_ui` Docker 启动。若相机已经启动，可直接运行下面命令。

### Sofa 指令

```bash
cd /workspace/Intern_g1

INSTRUCTION="Move toward the sofa and stop in front of it." \
KEEP_DEPS_RUNNING=1 \
PRIMARY_RGB_TOPIC=/moz_robot/camera/cam_high/image_raw \
SECONDARY_RGB_TOPIC=/moz_robot/camera/cam_high_extra/image_raw \
ODOM_TOPIC=/moz1/odom_global \
CONTROL_MODE=mpc_tracking \
TRAJECTORY_TRACKER=hybrid \
COMMAND_ANGULAR_SIGN=1.0 \
SPIN_CONTROL_MODE=fallback_turn \
bash scripts/realworld/run_vln_dishwasher_oneclick.sh
```

### Turn around + Sofa 指令

```bash
cd /workspace/Intern_g1

INSTRUCTION="Turn around, move toward the sofa, and stop in front of it." \
KEEP_DEPS_RUNNING=1 \
PRIMARY_RGB_TOPIC=/moz_robot/camera/cam_high/image_raw \
SECONDARY_RGB_TOPIC=/moz_robot/camera/cam_high_extra/image_raw \
ODOM_TOPIC=/moz1/odom_global \
CONTROL_MODE=mpc_tracking \
TRAJECTORY_TRACKER=hybrid \
COMMAND_ANGULAR_SIGN=1.0 \
SPIN_CONTROL_MODE=fallback_turn \
bash scripts/realworld/run_vln_dishwasher_oneclick.sh
```

### White dishwasher 指令

```bash
cd /workspace/Intern_g1

INSTRUCTION="Move toward the white dishwasher and stop in front of it." \
KEEP_DEPS_RUNNING=1 \
PRIMARY_RGB_TOPIC=/moz_robot/camera/cam_high/image_raw \
SECONDARY_RGB_TOPIC=/moz_robot/camera/cam_high_extra/image_raw \
ODOM_TOPIC=/moz1/odom_global \
CONTROL_MODE=mpc_tracking \
TRAJECTORY_TRACKER=hybrid \
COMMAND_ANGULAR_SIGN=1.0 \
SPIN_CONTROL_MODE=fallback_turn \
bash scripts/realworld/run_vln_dishwasher_oneclick.sh
```

一键脚本行为：

- `/health` 已可用时复用推理服务，否则自动启动。
- `/livox/lidar` 已有数据时复用雷达，否则自动启动。
- `velocity_smoother`、`collision_monitor`、`message_forward` 已在线时复用导航速度链路，否则自动启动 Nav2。
- 主相机必须有图像，否则退出并提示相机启动命令。
- 结束后自动发布零速度和 `/robot_nav_stop_task=true`。
- 结果保存到 `experiment_records/vln_oneclick_YYYYmmdd_HHMMSS/`。

## 一键脚本状态管理

检查当前依赖复用状态：

```bash
cd /workspace/Intern_g1
ACTION=status bash scripts/realworld/run_vln_dishwasher_oneclick.sh
```

停止一键脚本启动过的推理服务、雷达和导航依赖：

```bash
cd /workspace/Intern_g1
ACTION=stop-deps bash scripts/realworld/run_vln_dishwasher_oneclick.sh
```

保留依赖以加速下次启动：

```bash
KEEP_DEPS_RUNNING=1 bash scripts/realworld/run_vln_dishwasher_oneclick.sh
```

不保留依赖，脚本退出时停止自己启动的后台进程：

```bash
KEEP_DEPS_RUNNING=0 bash scripts/realworld/run_vln_dishwasher_oneclick.sh
```

## 分开启动

分开启动适合调试每个环节，或需要手动观察日志时使用。

### 1. 启动相机

相机在外部 `agent_ui` Docker 中启动。如果已经启动，可跳过。

```bash
docker exec -it agent_ui bash
cd /home/spirit-ai/codebase/runcode/livingroom_debug/mozbrain
./moz1_run_robot_control_posttrain_livingroom_sync.sh
```

确认相机话题：

```bash
source /workspace/nav_ws/install/setup.bash
ros2 topic echo --once /moz_robot/camera/cam_high/image_raw sensor_msgs/msg/Image
ros2 topic echo --once /moz_robot/camera/cam_high_extra/image_raw sensor_msgs/msg/Image
```

### 2. 启动雷达

```bash
cd /home/spirit-ai/thor_livox_mid360s_installer/livox_ws
source install/setup.bash
ros2 launch livox_ros_driver2 msg_MID360s_launch.py
```

检查：

```bash
source /workspace/nav_ws/install/setup.bash
ros2 topic echo --once /livox/lidar
```

### 3. 启动导航与速度链路

```bash
cd /workspace
source /workspace/nav_ws/install/setup.bash
ros2 launch nav2_bringup bringup_spirit_glim_launch.py
```

这里主要需要以下节点和链路：

```text
velocity_smoother
collision_monitor
message_forward
/moz1/odom_global
/cmd_vel_nav -> /cmd_vel_smoothed -> /cmd_vel -> /mx_base_vel_command
```

检查节点：

```bash
source /workspace/nav_ws/install/setup.bash
ros2 node list | grep -E 'velocity_smoother|collision_monitor|message_forward'
ros2 topic echo --once /moz1/odom_global nav_msgs/msg/Odometry
```

### 4. 启动 InternNav 推理服务

```bash
cd /workspace/Intern_g1
SKIP_RUNTIME_INSTALL=1 bash docker_start_server_in_container.sh > /tmp/internnav_server.log 2>&1 &
tail -f /tmp/internnav_server.log
```

检查健康状态：

```bash
curl http://127.0.0.1:5801/health
```

日志中应能看到 flash-attn 检查通过，并使用 `flash_attention_2`。

如果首次启动或依赖缺失，可取消快速路径：

```bash
cd /workspace/Intern_g1
SKIP_RUNTIME_INSTALL=0 bash docker_start_server_in_container.sh > /tmp/internnav_server.log 2>&1 &
```

### 5. 启动 VLN 实机客户端

下面命令会启用真实运动。运行前确认周围环境安全，并确认急停方式可用。

```bash
cd /workspace/Intern_g1
source /workspace/nav_ws/install/setup.bash

RESULT_DIR="/workspace/Intern_g1/experiment_records/vln_manual_$(date +%Y%m%d_%H%M%S)"

CONTROL_MODE=mpc_tracking \
TRAJECTORY_TRACKER=hybrid \
COMMAND_ANGULAR_SIGN=1.0 \
ENABLE_MOTION=1 \
MOTION_ARMED=YES \
ALLOW_FORWARD_MOTION=1 \
FORWARD_ARMED=YES \
ALLOW_LEGACY_IDLE_STACK=1 \
PRIMARY_RGB_TOPIC=/moz_robot/camera/cam_high/image_raw \
SECONDARY_RGB_TOPIC=/moz_robot/camera/cam_high_extra/image_raw \
ODOM_TOPIC=/moz1/odom_global \
INSTRUCTION="Move toward the sofa and stop in front of it." \
MAX_INFERENCES=0 \
MAX_MOTION_STEPS=0 \
SPIN_CONTROL_MODE=fallback_turn \
SPIN_REPLAN_FPS=1.0 \
DISCRETE_TURN_DEGREES=15.0 \
MAX_FALLBACK_TURN_DEGREES_PER_SEGMENT=45.0 \
MAX_FALLBACK_TURN_TOTAL_DEGREES=180.0 \
TURN_ONLY_MAX_INFERENCES=8 \
FALLBACK_TURN_TIMEOUT=20.0 \
TURN_DIRECTION_CHECK_DELAY=0.5 \
TURN_DIRECTION_MIN_YAW_DEGREES=3.0 \
MPC_ODOM_MAX_AGE=1.0 \
MPC_START_GRACE=1.0 \
MPC_MAX_TRACK_DISTANCE=0.8 \
MPC_HORIZON=12 \
MPC_REF_GAP=3 \
MPC_DESIRED_V=0.10 \
MPC_V_MAX=0.15 \
MPC_W_MAX=0.25 \
MPC_GOAL_TOLERANCE=0.05 \
MPC_CONTROL_RATE=10.0 \
MPC_MAX_SOLVE_TIME=0.15 \
MPC_PROGRESS_TIMEOUT=2.0 \
MPC_MIN_PROGRESS=0.03 \
MPC_MAX_CROSS_TRACK=0.25 \
PURE_PURSUIT_LOOKAHEAD=0.25 \
PURE_PURSUIT_ALIGN_DEGREES=45.0 \
PURE_PURSUIT_PROGRESS_TIMEOUT=3.0 \
MAX_FORWARD_DISTANCE=0.20 \
LINEAR_SPEED=0.10 \
ANGULAR_SPEED=0.20 \
MAX_BASE_LINEAR=0.20 \
MAX_BASE_ANGULAR=0.30 \
YAW_TOLERANCE_DEGREES=2.0 \
MOTION_TIMEOUT=15.0 \
PREFLIGHT_WAIT=8.0 \
RESULT_DIR="$RESULT_DIR" \
bash scripts/realworld/run_minimal_closed_loop.sh
```

切换指令时只改 `INSTRUCTION`，例如：

```bash
INSTRUCTION="Turn around, move toward the sofa, and stop in front of it."
INSTRUCTION="Move toward the white dishwasher and stop in front of it."
```

## 停止流程

停止 VLN 客户端：

```text
在客户端终端按 Ctrl+C
```

强制发布零速度和导航停止：

```bash
source /workspace/nav_ws/install/setup.bash
ros2 topic pub --once /cmd_vel_nav geometry_msgs/msg/Twist '{}'
ros2 topic pub --once /robot_nav_stop_task std_msgs/msg/Bool '{data: true}'
```

停止推理服务：

```bash
pkill -f http_internvla_server.py
```

停止一键脚本启动的依赖：

```bash
cd /workspace/Intern_g1
ACTION=stop-deps bash scripts/realworld/run_vln_dishwasher_oneclick.sh
```

雷达、导航和相机如果是手动启动的，分别在对应终端按 `Ctrl+C`。

## 结果文件

每次运行结果目录通常包含：

```text
input_*.jpg                  每轮输入图像
response_*.json              每轮模型原始响应
events.jsonl                 客户端动作解析、控制和状态事件
client.log                   客户端日志
metadata.json                本次任务配置
rosbag/                      速度链路和里程计 rosbag
summary.json                 rosbag 分析结果
summary.log                  分析日志
post_run_analysis.md         一键脚本生成的运行总结
startup_logs/                一键脚本启动日志
```

重点分析字段：

```text
discrete_action              模型离散动作，例如 2=左转，3=右转
trajectory                   模型局部轨迹，进入 hybrid tracker 后生成速度
pixel_goal                   模型像素目标点，作为 grounding 证据
/cmd_vel_nav                 客户端发布的速度
/mx_base_vel_command         最终转发到底盘的速度命令
/moz1/odom_global            实际运动轨迹和 yaw 变化
```

## 常见问题

### 相机未启动

现象：

```text
Primary camera has no frames
```

处理：

```bash
docker exec -it agent_ui bash
cd /home/spirit-ai/codebase/runcode/livingroom_debug/mozbrain
./moz1_run_robot_control_posttrain_livingroom_sync.sh
```

### 推理服务不健康

检查：

```bash
curl http://127.0.0.1:5801/health
tail -n 100 /tmp/internnav_server.log
```

重新启动：

```bash
cd /workspace/Intern_g1
SKIP_RUNTIME_INSTALL=1 bash docker_start_server_in_container.sh > /tmp/internnav_server.log 2>&1 &
```

### 速度链路缺节点

检查：

```bash
source /workspace/nav_ws/install/setup.bash
ros2 node list | grep -E 'velocity_smoother|collision_monitor|message_forward'
```

重新启动导航：

```bash
cd /workspace
source /workspace/nav_ws/install/setup.bash
ros2 launch nav2_bringup bringup_spirit_glim_launch.py
```

### 模型持续输出转向

检查：

```bash
tail -f /workspace/Intern_g1/experiment_records/vln_oneclick_*/client.log
```

重点看：

```text
response_*.json 中是否只有 discrete_action
是否有 trajectory
是否有 pixel_goal
events.jsonl 中是否进入 MODEL_TURN_ONLY
odom yaw 是否按命令方向真实变化
```

如果图像中目标已经清晰可见但模型仍持续输出转向，优先按模型 grounding 问题处理，而不是先修改 ROS 速度链路。
