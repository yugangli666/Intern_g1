================================================================================
  启动脚本 (按推荐顺序)
================================================================================

1. docker_run_server.sh (推荐新手)
   - 全自动化启动脚本
   - 自动检查环境、启动容器、安装依赖、启动服务
   - 交互式提示，适合首次使用
   用法: bash docker_run_server.sh

2. docker_quick_start.sh (推荐熟悉用户)
   - 快速启动容器
   - 需要手动启动推理服务
   用法: bash docker_quick_start.sh

3. docker_start_server_in_container.sh (容器内执行)
   - 在已运行的容器内启动推理服务
   - 包含依赖安装和服务启动
   用法: docker exec -it internnav_server bash /workspace/InternNav/docker_start_server_in_container.sh

================================================================================
  快速启动命令
================================================================================

# 方式一：全自动（推荐新手）
cd /home/spirit-ai/Intern_g1
bash docker_run_server.sh

# 方式二：快速启动（推荐熟悉用户）
cd /home/spirit-ai/Intern_g1
bash docker_quick_start.sh
docker exec -it internnav_server bash /workspace/InternNav/docker_start_server_in_container.sh

# 方式三：手动启动（推荐开发者）
cd /home/spirit-ai/Intern_g1
docker run -d --name internnav_server --gpus all --net=host \
    -v /home/spirit-ai/Intern_g1:/workspace/InternNav:rw \
    -v /home/spirit-ai/model_vln:/workspace/model_vln:ro \
    harbor.i.spirit-ai.com:443/slam_nav/nav_release:jazzy-thor-vln-deps-fixed-20260714 \
    bash -lc "while true; do sleep 3600; done"
docker exec -it internnav_server bash
cd /workspace/InternNav && pip3 install -r requirements/internvla_n1.txt
python3 scripts/realworld/http_internvla_server.py --device cuda:0 --model_path /workspace/model_vln --port 5801

================================================================================
  故障排查快速参考
================================================================================

问题: 容器无法启动
解决: docker run --rm --gpus all nvidia/cuda:12.0.0-base-ubuntu22.04 nvidia-smi

问题: 端口被占用
解决: SERVER_PORT=5802 bash docker_run_server.sh

问题: GPU内存不足
解决: 修改 --num_history 从 8 降到 4

问题: 模型加载失败
解决: ls -lh /home/spirit-ai/model_vln/*.safetensors (检查4个文件是否存在)

问题: 依赖安装失败
解决: docker exec -it internnav_server bash
      pip3 install --upgrade pip
      pip3 install -r requirements/internvla_n1.txt
